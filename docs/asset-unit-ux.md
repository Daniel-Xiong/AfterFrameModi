# 资产单元的界面方案

对象模型见 [`asset-unit-model.md`](asset-unit-model.md)。本文只谈 **人怎么看见、怎么点、怎么删**。

原则：**图库里一张卡 = 一次拍摄（或一组连拍的封面）**。RAW、crop、连拍废片都不是默认格子。用户不需要知道「层」。

---

## 1. 给用户的词，不要给内部词

| 内部 | 界面上说 | 不要说 |
|------|----------|--------|
| 文件行 | （几乎不说；检查器「源文件」里才出现路径） | 资产记录 |
| 拍摄单元 (1) | **照片** | 资产单元、Capture Unit |
| 版本族 (2) | **版本** | 资源集、Resource Set |
| 连拍组 (3) | **连拍** | Burst Group、第 3 层 |
| display / keeper | **封面**（连拍）/ **当前版本**（单张） | representative |
| Collection | 继续叫侧栏 **文件夹**；检查器动作「加入画册」可作同义词 | 把文件夹改成另一套导航 |
| 相似簇 | **相似照片** | 外挂、overlay |

侧栏数字改成「照片」计数（拍摄单元 + 独立连拍封面），不再用磁盘文件数。有 RAW 的照片仍可用现有「含 RAW」筛选，不必多一个入口。

---

## 2. 默认浏览：叠卡，不拆卡

打开图库时：

- 一次快门（JPG，或 JPG+RAW，或仅 RAW）→ **一张卡**
- 有 crop / 导出 / AI → 仍是这张卡，右下角小徽章 `2`（版本数）
- 连拍 → **一张叠卡**，左下角 `连拍 · N`，缩略图用封面（默认最高星，否则最早一张）
- 视频不变

点击 = 选中这张照片（连拍则选中封面）。双击 / 空格 = 灯箱，看的是 **当前版本**，不是 RAW 文件。

拖进文件夹、评分、标注、编辑，对象都是 **当前版本**。加入画册的是这张成片；若用户从版本条里选了 crop，加入的就是那一版。

---

## 3. 卡片长什么样

沿用现有暗色网格：细选中金环、无描边底板。只加两类**小**徽章，不堆图标。

```
┌─────────────────┐
│                 │  缺失 / 人脸：保持现有位置
│     预览        │
│                 │
│ 连拍·5     ★★   │  左下连拍（半透明黑底）；评分可沿用检查器，卡片上不必再放星
│            ▢ 3  │  右下版本数（仅 >1 时出现）
└─────────────────┘
文件名
```

- **连拍徽章**：可点。点徽章 = 展开连拍（见 §4），点卡片其余区域 = 选中封面。
- **版本徽章**：可点。点开检查器版本条并滚动到该节；不在网格里把 crop 铺开。
- 叠卡可用 2px 错位阴影暗示「底下还有」，不要做成真正的扇形堆，以免打乱网格对齐。

---

## 4. 连拍：主路径是「展开 → 挑留 → 丢掉」

连拍的产品任务是 **从一串里留下 1～几张**，不是再发明一种相册。

### 4.1 展开

三种等价入口，结果同一套 UI：

1. 点卡片左下 **连拍 · N**
2. 灯箱里点底栏「连拍」
3. `B`（Burst）——有连拍时展开，无则无操作

展开后 **不离开图库**：在该卡下方插入一条横滑胶片（现有检查器 ThumbnailStrip 的放大版），网格其余卡片下移。不要用模态。瀑布流/两端对齐里胶片仍插在该卡逻辑位置下，避免错位乱跳。

胶片里：

- 每格是该连拍里一张 **照片的当前版本**
- 封面有细金环 + 角标「封面」
- 已评分的显示星
- 当前选中用现有选中环

### 4.2 挑选

| 操作 | 行为 |
|------|------|
| 单击一格 | 选中这张；检查器切到它；网格封面 **先不换**（避免挑图时卡乱跳） |
| 双击 / 空格 | 灯箱从这张开始，左右键只在该连拍内走（见 §6） |
| 点「设为封面」或 `F` | 这张成为网格叠卡封面，立刻换缩略图 |
| `1`–`5` / `0` | 给 **当前这张** 打星（不是整组） |
| `X` 或 Delete | 从目录去掉这张拍摄单元（确认框写清：RAW/JPG 一起从目录移除；磁盘删除走现有「从磁盘删除」） |
| `Shift+X` | 丢掉 **未选中且不是封面** 的其余连拍（二次确认：「从目录去掉 N 张，留下封面/已选」） |
| Esc / 再点徽章 | 收起胶片；网格回到叠卡 |

多选胶片格子：Cmd 点、Shift 范围，与图库一致。拖到侧栏文件夹 = 只加入选中的那些照片。

整组进画册：胶片工具条「加入文件夹」默认只加 **封面 + 已选**；按住 Alt 改为「整组」。不要静默把 30 张废片拖进画册。

### 4.3 封面规则（用户可感知）

自动：最高星 → 同星取最早。用户「设为封面」后钉住，直到再改或那张被删。

删掉封面：自动落到剩余里最高星/最早，toast：「连拍封面已换成 xxx」。

---

## 5. 版本：始终在「这一张」里面

Crop、压缩、编辑器导出、AI 重绘 **不出现新格子**。

### 5.1 检查器

现有「其他版本」上移到预览正下方，改名为 **版本**，成为该照片的第二视觉焦点（仅次于大预览）。

顺序：当前版（标「当前」）→ 主版 → 按时间。每格悬停显示种类：裁切 / AI 重绘 / 导出。

单击切当前版（图库卡、灯箱、编辑对象都跟着换）。右键：设为当前、加入文件夹、从目录删除这一版（主版不能从这里删，只能删整张照片）。

RAW 不进版本条，仍在 **源文件**：成品路径、RAW 路径、.xmp。点路径仍「在访达中显示」。

### 5.2 编辑产出

编辑器保存 / crop / 重绘：写入该照片的新版本，**当前版切到新文件**，网格卡预览换成新成片。Toast：「已保存为新版本」。不要问「另存为新照片吗」。

拼图例外：多源合成仍是 **新照片**（独立拍摄单元），检查器保留「源图像」。

### 5.3 当前版 vs 主版

- **主版**：导入时那张 JPG（或仅 RAW 时的 RAW 预览），不能被 crop 覆盖。
- **当前版**：图库和灯箱默认看的；可换成任意版本。

「含 RAW」筛选看拍摄单元是否带 RAW，与当前是不是 crop 无关。

---

## 6. 灯箱：看一张，顺带扫连拍/版本

默认仍是单张大图。底栏现有「编辑」旁增加两枚胶囊，**仅有内容时出现**：

- `连拍 3/12` — 本组序号；点开底缘一条胶片（和网格展开同一数据）
- `版本 1/4` — 点开版本胶片

键盘：

| 键 | 无胶片 | 连拍胶片开着 | 版本胶片开着 |
|----|--------|--------------|--------------|
| ← → | 图库上一张/下一张（叠卡为单位） | 连拍内上一张/下一张 | 版本间切换 |
| `[` `]` | 版本 | 版本 | 版本 |
| `{` `}` | 连拍内（无连拍则无操作） | 连拍内 | 连拍内 |
| `B` | 开关连拍胶片 | 关 | 开连拍、关版本 |
| `V` | 开关版本胶片 | 开版本、关连拍 | 关 |
| `F` | 设为连拍封面 | 同左 | 无操作 |
| `E` | 编辑当前版 | 同左 | 同左 |

两组胶片不同时开，避免底栏打架。Esc 先关胶片，再关灯箱。

---

## 7. 检查器信息架构（从上到下）

1. 预览  
2. **版本**（>1 才展开默认打开）  
3. **连拍**（在组内才出现：胶片 +「设为封面」）  
4. 人物  
5. 属性（评分、尺寸、类型）  
6. 源文件（成品 / RAW / sidecar）  
7. 相机、曝光、日期、位置  
8. **相似照片**（有簇才出现，见 §9）

连拍和版本都是 ThumbnailStrip，不要新控件类型。相似是列表，强调「这是建议，不是结构」。

---

## 8. 画册、人物、地图：还是筛选，不是第四层叠卡

- **文件夹/画册**：条目 = 当时加入的那一 **版本**。画册网格 **不折叠** 连拍（用户明确要留下的那几张应并列）。卡上仍可显示「这张属于某连拍」，点徽章回到图库并展开该连拍。
- **人物 / 地图 / 标签 / 评分**：过滤拍摄单元；连拍只要有一张命中，叠卡出现。点进后胶片里未命中的格变暗，仍可点，避免「人在第 3 张但封面是第 1 张」找不到。
- 侧栏「全部」计数 = 默认图库卡数（叠卡算 1）。检查器或状态栏次要行可写「N 张照片 · M 个文件」，需要时才看文件数。

---

## 9. 相似照片：一次会话，不是一种浏览模式

不要做成常驻侧栏项。它是 **打扫工具**。

入口：菜单「图库 → 查找相似照片」，或选中 1 张时右键「查找相似」。跑完 JobDock 出现进度。

完成后 **临时视图**（工具条黄条，和「人物筛选中」一样可关闭）：

- 每簇一组：大图候选 + 右侧小图
- 默认勾选「建议删除」（非当前、非画册内、非连拍封面）
- 主按钮：**从目录去掉已勾选**
- 次按钮：保留全部、合并到连拍（仅当时间/相机也像连拍；不确定则灰掉并 tooltip「不像连拍，请用连拍展开来挑」）

关黄条 = 丢掉勾选，结构不变。连拍成员不进相似簇（已有连拍流程）。

---

## 10. 键盘总表（图库）

在现有 1–5 评分、E 编辑、方向键、Esc 上增加：

| 键 | 作用 |
|----|------|
| `B` | 展开/收起选中项的连拍 |
| `V` | 检查器聚焦版本条（灯箱则开版本胶片） |
| `F` | 将选中张设为连拍封面 |
| `X` | 从目录去掉选中照片（连拍展开时只去当前张） |
| `Shift+X` | 连拍展开时去掉其余废片 |

Cmd 点、框选仍针对 **可见卡片**（叠卡为单位）。要多选连拍里的单张，必须先展开。

---

## 11. 空态与边界

| 情况 | 表现 |
|------|------|
| 仅 RAW | 一张卡，预览用已有 RAW 预览；源文件里 RAW 即成品 |
| JPG+RAW | 一张卡；源文件两行 |
| 导入后尚未成组 | 短暂各卡一张，组好后合并（已有 JobDock）；不要闪两次布局，等本批 import 结束再刷新折叠 |
| 连拍只有 1 张（删剩） | 自动解散连拍，变普通卡，无徽章 |
| 用户拆开误报连拍 | 胶片菜单「从连拍移出」；移出后独立成卡。不做「手动把两张拼成连拍」直到有明确需求 |
| 版本全删只剩主版 | 徽章消失 |
| 缺失原片 | 沿用缺失徽章；展开连拍时缺的格打同样标记 |

---

## 12. 明确不做

- 不在设置里暴露「第 1/2/3 层」或让用户选「浏览文件 / 浏览单元」。默认永远是照片卡。
- 不在网格里同时铺开连拍每一张（那是 Lightroom 展开叠图的老问题：一滚就丢）。
- 相似不做成智能文件夹。
- RAW 不单独占格（「含 RAW」筛选已够）。
- 不把 .xmp 做成可点的第三张照片。

---

## 13. 建议落地顺序（只动 UI）

后端分组已在 catalog 里。界面建议三步，每步可单独用：

**A. 读得懂**  
默认折叠代表与连拍封面；卡徽章；检查器版本上移 + 连拍条 + 源文件 sidecar。无新快捷键也可以用。

**B. 连拍能挑**  
网格展开胶片、封面、X / Shift+X、灯箱连拍胶片与 `{` `}`。这是新模型的核心收益。

**C. 打扫**  
相似照片会话、画册计数改为照片数、人物筛选时连拍未命中格变暗。

A 即可让「JPG+RAW 不再并排两张卡」被看见；B 才让「连拍」从数据变成动作。

---

## 14. 原子方案（用来勾选组合）

每一项可单独做、单独测。标了「依赖」的项，没有前置会显得残缺，但仍可先做数据侧。

### 看见（只改变默认格子）

| ID | 做什么 | 依赖 |
|----|--------|------|
| **G1** | 图库折叠：JPG+RAW 一张卡，隐藏 RAW 格 | 无 |
| **G2** | 图库折叠：crop/导出/AI 不占新格 | 无 |
| **G3** | 图库折叠：连拍只显示封面一张卡 | 无 |
| **G4** | 卡片版本数徽章（>1 才出现） | G2 才有意义 |
| **G5** | 卡片连拍数徽章 | G3 才有意义 |
| **G6** | 连拍卡 2px 错位阴影 | G3 |
| **G7** | 侧栏/状态栏计数改为照片数（叠卡算 1） | G1–G3 任一 |

### 检查器（不改网格也能用）

| ID | 做什么 | 依赖 |
|----|--------|------|
| **I1** | 「版本」条上移到预览下；单击切换当前版 | G2 更顺 |
| **I2** | 「连拍」条：兄弟图 + 设为封面 | G3 |
| **I3** | 源文件增加 .xmp 路径 | G1 |
| **I4** | 「相似照片」只读列表（点过去） | 无 |

### 连拍动作

| ID | 做什么 | 依赖 |
|----|--------|------|
| **B1** | 点徽章，卡下插入胶片展开 | G3+G5 |
| **B2** | 单击胶片只选中、不换封面 | B1 |
| **B3** | `F` / 按钮设为封面，这时才换卡图 | B1 |
| **B4** | `X` 从目录去掉当前这张 | B1 |
| **B5** | `Shift+X` 去掉其余废片（二次确认） | B4 |
| **B6** | `B` 开关展开 | B1 |
| **B7** | 灯箱连拍胶片 + `{` `}` 组内切 | G3 |
| **B8** | 拖进文件夹只加选中；Alt 才整组 | B1 |

### 版本动作

| ID | 做什么 | 依赖 |
|----|--------|------|
| **V1** | 编辑器保存 / crop / 重绘 = 新版本并切当前 | I1 或 G2 |
| **V2** | 灯箱版本胶片 + `[` `]` | I1 |
| **V3** | 版本右键：设为当前、删这一版（主版不能删） | I1 |

### 筛选与打扫

| ID | 做什么 | 依赖 |
|----|--------|------|
| **F1** | 人物/地图：连拍有一张命中就出叠卡；展开后未命中格变暗 | B1 |
| **F2** | 画册仍按加入的那一版平铺，不折叠连拍 | 无 |
| **S1** | 「查找相似」任务 + 顶栏黄条会话 | 无 |
| **S2** | 黄条里勾选建议删除、批量从目录去掉 | S1 |
| **S3** | 像连拍的簇提供「并入连拍」（不像则灰掉） | S1+G3 |

### 明确不做（也可当否决项）

| ID | 不做什么 |
|----|----------|
| **X1** | 设置里「按文件浏览 / 按照片浏览」开关 |
| **X2** | 网格默认铺开连拍每一张 |
| **X3** | 相似做成常驻智能文件夹 |
| **X4** | RAW 单独占格 |
| **X5** | 手动把任意两张拼成连拍（可后补，不进第一波） |

### 现成组合示例

- **最小能看懂**：`G1+G2+G3+G5+I1+I2+I3`
- **连拍能挑**：上面 + `B1+B2+B3+B4+B5+B6`
- **灯箱补齐**：`B7+V2`
- **编辑闭环**：`V1+V3`
- **打扫**：`S1+S2`（`S3` 可再后）
- **计数/筛选抛光**：`G7+F1+F2`

回复编号即可，例如 `G1+G2+G3+B1+B3+V1`。
